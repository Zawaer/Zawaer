### Hey, I'm Toivo

17, from Espoo, Finland. I build across the whole stack: PCBs and firmware, web and mobile apps, and quantum algorithms. Final year at Otaniemen lukio.

**Things I've built**

- [**renki**](https://github.com/Zawaer/renki): run Claude Code on your own server and drive it from your phone. Self-hosted daemon with web, VS Code and Android clients.
- [**bananagrams-assistant**](https://github.com/Zawaer/bananagrams-assistant): point a phone at scattered tiles. A YOLO11 model reads the letters and a C++ solver builds a valid grid in under 2 seconds.
- [**oikotie**](https://github.com/Zawaer/oikotie): browser extension that skips the login steps for Finnish school platforms (Kampus, Nova, Studeo). On the Chrome and Firefox stores.
- [**haggle**](https://github.com/Zawaer/haggle): an agent that finds second-hand listings, vets them for scams and haggles with sellers. Built in a day with my team.
- [**unhitch**](https://github.com/Zawaer/unhitch): stops a sleeping MacBook from holding one of your headphones' two Bluetooth slots.

**Hardware**

- **F-35B VTOL RC jet**: 3D printed and designed to hover on two 70 mm EDFs and a thrust-vectoring nozzle. In progress: the nozzle's first test parts are printed.

- [**zpad**](https://github.com/Zawaer/zpad): 8-key macropad with a rotary encoder and an OLED running little physics animations.
